# Analisador-emprestimo-estudantil
Sistema para disponibilizar empréstimo para estudantes

O objetivo desse programa é realizar uma análise de viabilidade de crédito, para isso ele coleta dados como a idade do estudante e sua renda mensal. Além disso, ele calcula se o valor das parcelas é seguro para o orçamento do cliente, garantindo que a dívida não ultrapasse 30% do salário dele.
